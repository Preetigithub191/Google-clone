# Google Clone

This is a simple Google homepage clone built using **HTML, CSS, and JavaScript**.

## Features:
- Responsive design similar to the original Google homepage
- Functional search bar (redirects to Google search)
- Dark mode toggle
- Hover effects and animations

## Technologies Used:
- **HTML** for structure
- **CSS** for styling (Flexbox, Grid, Animations)
- **JavaScript** for interactivity (Search, Dark Mode)
